# AI 기반 안무 피드백 서비스 (Move AI Scan)


## 📖 프로젝트 개요

K-POP 댄스 연습생 및 아티스트를 위한 **실시간 동작 분석 및 피드백** 솔루션입니다.  
안무 선생님의 동작에서 관절 키포인트를 추출하고, 음악의 리듬까지 고려해 **정밀한 피드백 캡션**과 **유사도 점수**를 제공합니다.



## 🚀 프레임워크

1. **영상 업로드**: 사용자 영상 및 기준 안무 영상 업로드  
2. **오디오 싱크**: Librosa & 크로스-상관 분석으로 영상·음성 정밀 동기화  
3. **스켈레톤 추출**: YOLOv8n으로 BBox Crop → MediaPipe Pose로 키포인트 추출  
4. **유사도 측정**: DTW, 각도 비교, Procrustes 분석으로 동작 유사도 계산  
5. **결과 확인**: React UI에서 점수, 피드백 캡션 및 비교 뷰 제공



## 🤖 AI 모델 구성

- **객체 탐지**: Ultralytics YOLOv8n으로 사람 영역 BBox 생성  
- **포즈 추정**: MediaPipe Pose로 33개 관절 키포인트 추출  
- **깊이 보정**: MiDaS + ResNet50으로 깊이 정보 보완 (실험 단계)


## 🎥 유튜브 영상 확보 및 전처리

- YouTube API/yt-dlp로 고품질 안무 영상 다운로드  
- FFmpeg로 필요한 프레임 추출 및 단편 영상 Crop



## 🔊 음성 파장 기반 싱크

- Librosa로 오디오 파형 추출  
- 파형 크로스-상관 분석으로 기준 영상에 맞춘 자동 싱크


## 🌐 웹 페이지 개발

- **Frontend**: React.js + Tailwind CSS  
- **Backend**: Flask (Python)  
- **API**: Axios를 통한 업로드/분석 요청 및 결과 전송  
- **UI**: 드래그·앤·드롭 업로드, 하이라이트 섹션


## 🌟 서비스 차별화 포인트

- **음악 리듬 연동**: 음악 비트와 정확히 동기화된 피드백  
- **실시간 캡션**: 프레임별 동작 오류 자동 감지 및 교정 문구 생성  
- **다차원 분석**: 각도·형태·시간축 통합 정밀 점수 제공


## 📊 다차원 유사도 분석 시스템

- **각도 분석**: 관절 상대 각도 차이 정량화  
- **Procrustes 분석**: 공간적 형태 유사도 최소제곱 측정  
- **DTW**: 시계열 정렬 기반 시퀀스 유사도 계산
